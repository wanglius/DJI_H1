# GUI 使用说明

## 启动与连接

进入 ground_app 文件夹，在配置文件里填写 broker / topic，运行：

```powershell
python run_ground_app.py --live --config config/ground_app.local.json
```

底部状态栏显示“正在连接 → 正在订阅 → 已订阅”。等待“已订阅”，检查设备 ID、任务 ID 和消息计数，再让 A 板开始测量。GUI 同时创建地面 SQLite 日志，并在配置开启时提供本机 HTTP。

界面默认使用简体中文；按钮与操作如下。API 字段、事件原始码、MQTT 主题和文件格式保持不变。底层异常详情可能保留原文，以便开发者检索排错。

应用优先使用微软雅黑或其他中文字体，并加载 Qt 简体中文翻译用于文件选择器等标准控件。事件名称、严重程度、连接状态、坐标插值质量和地图故障提示也在展示层翻译；未识别的事件码仍保留原文，以便对照日志。此本地化仅作用于 ground_app，不修改原 mission viewer。

| 控件 | 操作 |
|---|---|
| 打开任务文件夹… | 打开一个 SD 任务目录，退出当前实时连接 |
| 连接实时遥测… | 选择完整 ground_app JSON 配置并建立接收会话 |
| 断开实时连接 | 排空接收任务、关闭 MQTT 与日志，保留当前视图 |
| 跟随最新光谱 | 每次刷新选择最新反射率；点击历史点后自动取消跟随 |
| 显示全部航迹 | 缩放到全部航迹 |

窗口支持地图、飞行信息、事件列表和反射率曲线。默认每秒刷新；MQTT 回调、重组、写盘和 ACK 发布都有自己的工作线程。HTTP 在自己的请求线程从接收状态更新，也不依赖地图完成渲染。

## 地图操作

离线坐标图可以鼠标滚轮缩放、右键拖动平移、双击适配全部航迹。点击蓝色测量点显示其反射率；事件列表点击也可定位相应事件。灰色航迹点是 GPS 记录，蓝色点是获得有效插值位置的光谱，事件按严重程度标记。

开启百度底图需要 `map.enabled=true`、合法 AK 和 WebEngine；叠加飞行位置还需 `map.allow_mission_coordinates=true`。地图采用卫星图，不显示道路/交通图层。当前保留 WGS84 输入，未做 BD09 转换；不要把底图偏移误判成测量数据漂移。

百度加载过程中仍可用离线图。错误 AK、网络超时、地图 JavaScript 报错、WebEngine 缺失或浏览器渲染进程退出，均只在地图面板显示不可用并回退。错误不会弹出阻塞对话框，不会改变 MQTT 配置、终止接收或清空任务。

恢复网络/修正配置后，通过重新选择实时配置重建地图。迟到的旧地图加载回调不会自动夺回显示。离线查看模式修改地图配置后重启应用。

## 光谱与跟随

跟随最新光谱 不以地图加载成功为前提，也不等待 GPS 配对。刚收到光谱时即使没有可插值位置，也能更新曲线；后续 GPS 补齐后，测量点才出现在地图上。

反射率纵轴是百分比。已确认本项目 H1 的每条完整光谱含 711 个样本，横轴为 340～1050 nm（含两端），间隔 1 nm，零基下标 i 对应 340+i nm。若记录不是 711 点，图表回退到样本序号并注明波长未知，不把其他长度强行拉伸到此范围。旧的 64 点合成示例也会使用该回退；新生成的示例为 711 点。

光谱详情显示测量时间、地面/天空帧号、样本质量、插值来源时钟及同步代次。数据的 UTC 保持原值，只在可读时间里应用时区偏移。

## 事件与异常

事件列表会显示开始/停止、握手、A–B 失联/恢复等固件实际发送的主要事件。“待定位” 表示事件时间尚未被有效 GPS 包围，事件本身仍会立即显示。

这些是遥测中的主要事件，不代表 SD 上完整的 `EVENTS.JSONL`。详细排查时同时保留 B 板串口日志和 SD 任务文件。

## SD 离线模式

```powershell
python run_ground_app.py --mission D:\F_0003 --config config/ground_app.local.json
```

任务目录可包含 `MISSION.JSON`、`GPS_TRACK.BIN`、`RAW_SPECTRA.BIN`、`REFLECTANCE.BIN`、`EVENTS.JSONL`。支持只有光谱文件的旧目录。加载不写入 SD 卡。受损文件尽量保留 CRC 正确的前缀记录，并在信息面板报告丢弃尾部；元数据主文件无效时尝试 `MISSION.BAK`。

SD 文件读取不会启动 MQTT。实时日志的 SQLite 通过命令行/Python replay 使用，当前 GUI 不直接打开 SQLite。

## 退出与数据保存

断开实时连接 或正常关闭窗口都会停止接收并关闭 SQLite。复制已关闭的数据库最简单；运行中 WAL 数据库可能还需要同名 `-wal` / `-shm` 文件，不要只复制主文件当作完整备份。

GUI 中的地图和曲线是快照。地面 SQLite 保存接收到的证据，机载 SD 保存设备本地完整记录，两者不可互相替代。GUI 本身异常退出时，本进程中的接收也会终止；本次隔离保证的是地图服务/面板失败不停止接收，并不声称整个应用进程被结束后还能继续运行。
